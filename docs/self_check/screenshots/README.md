# 체크리스트 증빙 보는 법

이 폴더의 PNG는 모두 실제 화면을 그대로 찍은 것이다(2026-10-23). 결과를 다시 그려 만든 이미지는 없다.
파일 이름 앞의 숫자는 [셀프 체크리스트](../self_checklist.md)의 항목 번호이고, 끝의 말은 찍은 화면의 종류다.

| 종류 | 파일 이름 끝 | 무엇을 찍었나 |
|---|---|---|
| 실제 서비스 화면 | (표시 없음) | 실행 중인 Streamlit 상담실·FastAPI 웹 화면에서 실제 질문으로 확인한 결과 |
| 터미널 실행 화면 | `_터미널` | Windows Terminal에서 실제 명령을 실행한 화면. 명령줄과 출력이 함께 보인다 |
| 코드 화면 | `_VSCode`, `_GitLab` | VS Code 또는 GitLab에서 실제 소스·폴더를 연 화면 |
| 문서 화면 | `_미리보기` | VS Code Markdown 미리보기로 연 저장소 문서 |

> 캡처에는 API 키, `.env` 값, 오류 추적 정보가 보이지 않는다. 21번 터미널 화면은 키 값을 출력하지 않고 일치 건수만 센다.
