# 셀프 체크리스트 (초안)

> AI 코어 프로젝트 2회차 · 3일차 검증 양식(`2회차_셀프·상호_체크리스트`)과 같은 항목·기준으로 작성한 **셀프 점검 초안**이다.
> 2026-10-23에 모든 항목을 **실제 서버와 실제 GMS 호출**로 다시 실행했다. 증빙은 [`checklist/`](checklist/)에 한글 파일명 PNG로 남겼고, 모두 실제 화면을 그대로 찍은 것이다.
> 서비스 동작은 실행 중인 앱 화면, 명령 결과는 터미널에서 실제 명령을 실행한 화면(`_터미널`), 구현 구조는 VS Code 코드 화면(`_VSCode`)과 GitLab 저장소 화면(`_GitLab`), 문서는 VS Code Markdown 미리보기 화면(`_미리보기`)으로 남겼다.
> 같은 결과를 배포 엑셀 양식에 옮긴 파일은 [`self-checklist.xlsx`](self-checklist.xlsx)이다(노란 입력 칸만 채움, 집계 수식 유지). 작성자가 결과를 직접 확인한 뒤 제출한다. 확인하지 않은 것은 통과로 적지 않는다.

## 점검 중 발견해 고친 것

- Streamlit 상담실의 "확인된 근거" 목록에서 법령과 판례가 종류 표시 없이 섞여 있었다. 8·19번을 위해 목록 줄마다 `법령 ·`/`판례 ·`를 붙였다(`rag/citations.py`, `test_citations`).
- 웹 화면에서 `.progress { display: flex }`가 `hidden` 속성을 덮어, 처리 중 문구가 결과가 나온 뒤에도 남아 있었다. `[hidden] { display: none !important; }`를 넣어 고쳤다(`web/static/styles.css`, `test_web_api`).
- 아직 남은 작은 문제: Streamlit에서 오류가 나면 진행 상태 줄이 "검증하고 있어요…"로 남는다. 바로 아래 오류 안내가 나와 사용에는 지장이 없다.
