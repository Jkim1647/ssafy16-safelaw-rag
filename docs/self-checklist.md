# 셀프 체크리스트 (초안)

> AI 코어 프로젝트 2회차 · 3일차 검증 양식(`2회차_셀프·상호_체크리스트.pdf`)과 같은 항목·기준으로 작성한 **셀프 점검 초안**이다.
> 2026-10-23에 각 항목을 다시 실행해 확인했고, 명령 출력은 `scripts/capture_checklist_evidence.py`로 PNG를 만들어 [`checklist/`](checklist/)에 넣었다.
> 작성자가 결과를 직접 확인한 뒤 PDF 양식에 옮겨 적는다. 확인하지 않은 것은 통과로 적지 않는다.

| 점검 유형 | 앱 작성자 | 점검자 | 점검 일시 |
|---|---|---|---|
| 셀프 | 김진영 | 김진영 (셀프) | 2026-10-23 |

결과 기준: **통과** 직접 실행해 기대한 결과를 확인함 · **실패** 실행했으나 기대와 다름 · **미확인** 실행하지 못함 · **해당없음** 선택하지 않은 항목.
증빙 경로는 이 문서(`docs/`) 기준이다. 캡처에는 API 키, OC 값, 오류 추적 정보가 보이지 않게 했다.

GMS 호출은 판례 수집(3·4번), Top-k·MMR 비교(6·16번), 실제 답변 1건(8·14·19번)에만 썼다. 나머지는 로컬 데이터·테스트·가짜 백엔드로 확인했다.

## 점검 중 발견한 것

- Streamlit 상담실의 "확인된 근거" 목록에는 법령과 판례가 종류 표시 없이 섞여 있었다. 8·19번을 위해 목록 줄마다 `법령 ·`/`판례 ·`를 붙이도록 고쳤다(`rag/citations.py`, `test_citations`).
- 오류가 나도 진행 상태 줄의 문구는 "검증하고 있어요…"로 남는다. 바로 아래에 오류 안내가 나와 사용에는 지장이 없지만, 상태 문구를 "처리하지 못했어요"로 바꾸면 더 분명하다.
