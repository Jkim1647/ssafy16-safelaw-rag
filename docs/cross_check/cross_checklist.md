# 상호 체크리스트 (점검자 작성)

> 다른 교육생이 **SafeLaw(앱 작성자: 김진영)**를 직접 실행해 확인하고 채우는 상호 점검 양식이다. 항목과 기준은 배포 양식 `2회차_셀프·상호_체크리스트`와 같다.
> 이 md 또는 같은 폴더의 [`cross_checklist.xlsx`](cross_checklist.xlsx)(배포 엑셀 양식, 노란 칸만 채움) 중 편한 쪽에 작성한다. 증빙 사진은 [`screenshots/`](screenshots/)에 넣는다.
> 작성자의 셀프 점검 결과는 [`../self_check/`](../self_check/)에 있다. 참고만 하고, 결과는 점검자가 직접 실행해 본 대로 적는다.

|---|---|---|---|

결과 기준: **통과** 직접 실행해 기대한 결과를 확인함 · **실패** 실행했으나 기대와 다름 · **미확인** 실행하지 못함 · **해당없음** 선택하지 않은 항목.

## 점검 준비

- 실행 방법은 저장소 README의 "실행 방법"을 따른다. Streamlit은 `streamlit run app.py`(http://localhost:8501), 웹 화면은 `uvicorn legal_rag.web.api:app --port 8000`.
- `.env`와 색인(`data/indexes/`)은 저장소에 없다. 점검자 PC에서 실행하려면 본인의 `GMS_KEY`·`LAW_API_OC`를 `.env`에 넣고 README 순서대로 색인을 만든다. 작성자 PC에서 실행해 확인해도 된다.
- 증빙 사진 이름은 `번호_내용.png`(예: `08_근거목록.png`)로 하고, 표의 증빙 칸과 엑셀 H열에 같은 이름을 적는다.
- 캡처에 API 키, `.env` 값이 보이지 않게 한다.
