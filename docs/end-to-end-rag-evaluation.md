# End-to-End RAG 평가

## 평가 설계

검색 결과를 실제 답변 생성과 인용 검증까지 연결한 상태로 총 30문항을 평가했다.

- 근로·임대차·상속 각 10문항
- 각 도메인: 답변 가능 8문항 + 거부 대상 2문항
- 답변 가능 문항: 판례 검색 평가셋에서 선정
- 거부 문항: 생활법률과 무관한 요청과 승소 확률 단정 요청
- 라벨 상태: 개발자 작성, 법률 전문가 미검수

## 지표 정의

| 지표 | 정의 |
|---|---|
| 답변 성공률 | 답변 가능 24문항 중 검증된 `answered` 비율 |
| 인용 정확성 | 답변된 결과 중 모든 주장에 실제 source ID가 있고 모든 출처가 공식 `law.go.kr`인 비율 |
| 근거 없는 주장 차단률 | 검증되지 않은 주장 문장이 최종 사용자 답변에 노출되지 않은 문항 비율 |
| 답변 거부 정확성 | 거부 대상 6문항 중 `no_evidence` 또는 `insufficient_evidence`로 차단된 비율 |
| 오거부율 | 답변 가능 문항이 최종 답변으로 이어지지 않은 비율 |
| 기대 판례 인용률 | 답변 성공 문항 중 개발자 라벨의 기대 사건번호가 실제 sources에 포함된 비율 |

`invalid_citations`와 `generation_failed`는 답변 거부 정확성의 정답으로 계산하지 않는다. 이 상태들은 안전하게 노출을 차단했지만 시스템 품질 실패이기 때문이다.

## 결과

| 지표 | 최초 파이프라인 | 재시도 개선 후 |
|---|---:|---:|
| 답변 성공률 | 0.4167 | 0.5417 |
| 인용 정확성 | 1.0000 | 1.0000 |
| 근거 없는 주장 차단률 | 1.0000 | 1.0000 |
| 답변 거부 정확성 | 1.0000 | 1.0000 |
| 오거부율 | 0.5833 | 0.4583 |
| 기대 판례 인용률 | 1.0000 | 0.6923 |

최종 상태는 `answered 13`, `insufficient_evidence 8`, `invalid_citations 9`다. 도메인별 답변 성공은 근로 4/8, 임대차 5/8, 상속 4/8이며 거부 문항은 각 도메인 2/2 모두 정확히 차단됐다.

기대 판례 인용률이 낮아진 이유는 답변 성공 건수가 늘면서 기대 판례 대신 검색된 법령 또는 다른 공식 판례만으로 검증된 답변도 포함됐기 때문이다. 인용 자체의 유효성은 100%지만, 평가셋의 핵심 판례 포함 여부는 별도 품질 지표로 계속 관리해야 한다.

## 적용한 개선

1. 인용 검증 실패 이유를 두 번째 생성 요청에 전달한다.
2. `evidence_quotes.quote`가 CONTEXT의 연속된 8자 이상 원문이어야 한다는 조건을 재강조한다.
3. 첫 응답이 `answerable=false`여도 한 번 더 보수적으로 재검토한다.
4. 두 번째 검토에서도 근거가 없으면 기존과 동일하게 차단한다.
5. 문항별 생성 시도 횟수와 인용 검증 실패 횟수를 결과에 저장한다.

## 남은 문제와 다음 개선

- 최종 9건의 `invalid_citations`가 가장 큰 병목이다.
- GMS에서 지원할 경우 JSON Schema 또는 구조화 출력 강제를 우선 검토한다.
- 답변 생성 모델과 인용 형식 교정 모델을 분리하는 2단계 생성도 비교한다.
- 기대 판례가 검색됐지만 인용되지 않은 문항은 프롬프트의 판례·법령 선택 기준을 조정한다.
- 현재 라벨은 전문가 미검수이므로 법률적 정답률로 해석하지 않는다.
