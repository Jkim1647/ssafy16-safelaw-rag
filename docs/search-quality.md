# 법령 검색 품질 검증

## 검증 환경

- 데이터: 현행법령 381개 조문, 386개 청크
- 임베딩: `text-embedding-3-small`, 1,536차원
- 저장소: Chroma cosine 검색
- 검색: 원문·재작성·법률 용어 다중 질의 + 가중 RRF
- 검색 범위: 사용자가 선택한 법률 도메인으로 제한

## 대표 자연어 질문 결과

| 도메인 | 질문 | 기대 근거 | 확장 검색 결과 | 판정 |
|---|---|---|---|---|
| 근로계약·부당해고 | 회사에서 카카오톡으로 내일부터 나오지 말라고 했어요 | 근로기준법 제27조 | 제27조 1위, 제28조 2위 | 통과 |
| 전세·임대차 보증금 | 집주인이 이사 나왔는데 전세금을 안 돌려줘요 | 주택임대차보호법 제3조의2·제3조의3 | 제3조의3 2위, 제3조의2 3위 | Top-3 통과 |
| 상속 | 아버지가 돌아가셨는데 빚이 더 많아요. 상속을 안 받으려면 언제까지 해야 하나요 | 민법 제1019조·제1041조 | 제1019조 1위, 제1041조 3위 | 통과 |

## 개선 전후 사례

`회사에서 카카오톡으로 내일부터 나오지 말라고 했어요`를 원문 하나로만 임베딩했을 때 근로기준법 제27조는 Top-5에 없었다. 다음 검색어 확장 후에는 제27조가 1위로 검색됐다.

```text
해고, 해고 통보, 서면통지, 해고사유, 해고시기, 해고 효력
```

- [x] LLM 실패 시 규칙 기반 폴백
- [x] 카테고리 메타데이터 필터 적용

- [ ] 질문 세트 30건 이상으로 Recall@5·MRR 측정
- [ ] 판례 색인 추가 후 법령/판례 검색 결과 분리 평가

## 알려진 한계

- 검색 결과는 관련 후보 조문이며 사용자 사건에 대한 법률 판단이 아니다.
- LLM이 만든 검색어에 부정확한 용어가 섞일 수 있어 원문·규칙 질의를 함께 사용한다.
- 현재 평가는 대표 질문 3건에 대한 초기 점검이다. 제출 전 도메인별 최소 10건의 고정 평가 질문을 추가해야 한다.
- 법령 개정 또는 임베딩 모델 변경 시 전체 색인과 평가 결과를 다시 생성해야 한다.
