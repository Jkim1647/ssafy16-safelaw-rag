# 판례 평가셋 전문가 검수 체크리스트

평가셋의 `review_status: developer_labeled`는 정답 확정이 아니라 검수 대기 상태다. 법률 전문가 또는 지도 리뷰어는 각 문항을 다음 기준으로 확인한다.

- 질문의 사실관계만으로 해당 법적 쟁점을 도출할 수 있는가
- `expected_case_numbers`가 질문의 핵심 쟁점을 직접 판단한 판례인가
- `acceptable_case_numbers`가 Top-5에 포함돼도 관련 결과로 볼 수 있는가
- 더 권위 있거나 최신인 대법원·전원합의체 판례가 누락되지 않았는가
- 판례가 변경·폐기되었거나 후속 판례와 충돌하지 않는가
- 질문 또는 판례 요약이 승소 가능성을 단정하거나 사실을 추가하지 않는가

검수 결과는 문항별로 `approved`, `needs_change`, `out_of_scope` 중 하나를 기록하고, 변경 이유와 검수일을 남긴다. 전체 30건이 승인되기 전에는 README와 결과 문서에 `법률 전문가 미검수` 표시를 유지한다.
