# RAG 사용 전후 답변 품질 비교 (심화 F2015)

## 방법

- 대표 질문 6개: 답변 가능 5개(분야별 1~2개) + 존재하지 않는 조문을 묻는 질문 1개. 모두 근거 없이 답하면 틀리기 쉬운 질문으로 골랐다.
- **RAG 미사용**: 같은 답변 생성 모델(`gpt-5.4-mini`)에 "질문에 답하고 근거 조문 번호를 제시하라, 확실하지 않으면 모른다고 답하라"는 시스템 프롬프트만 주었다.
- **RAG 사용**: SafeLaw 파이프라인(LangGraph retrieve/generate, Top-k 5, 판례 실시간 보강 끔)으로 답했다.
- 답변에 나온 `법령명 제N조`를 수집된 법령 데이터셋과 자동 대조하고, 기대 조문 언급 여부를 기록한 뒤 개발자가 세 기준으로 판정했다. 법률 전문가 검수는 거치지 않았다.

```powershell
python scripts/compare_rag_baseline.py
```

원문 답변 전체는 [`data/evaluation/rag_before_after.json`](../data/evaluation/rag_before_after.json)에 있다. 2026-10-22에 두 번 실행했다. 1차(커밋 `607dc2a`)는 제1112조 검색 규칙과 삭제 조문 제외 전, 2차(현재 JSON)는 두 수정과 검색어 변환 모델 변경(`gpt-5.4-mini`) 후다.

| 기준 | RAG 미사용 | RAG 사용 |

## 해석과 한계

- 흔한 질문(해고 서면통지, 금품 청산, 상속포기 기한)은 모델 사전지식만으로도 대체로 맞았다. RAG의 차이는 **최근 개정**과 **존재하지 않는 대상**에서 뚜렷했다. 법률은 개정이 잦으므로, 근거 원문과 시행일을 함께 보여 주는 것이 핵심이다.
- RAG 답변은 인용 검증 때문에 RAG 미사용 답변보다 짧고 범위가 좁다. 경매 질문은 두 번 모두 소액임차인 최우선변제(제8조) 같은 관련 정보를 다루지 못했다(1차는 3차 교정에서 조문 하나만 남음).
- 1차 실행에서 유류분 질문에 제1112조가 검색되지 않은 문제는 검색어 규칙을 보강해 2차에서 해결했다. RAG 품질은 검색 단계에 크게 좌우된다.
- RAG 미사용 답변은 같은 질문에도 실행마다 정답 여부가 달라졌다. RAG는 근거가 없을 때 항상 같은 방식으로 차단했다.
- 질문 6개, 개발자 판정이므로 일반화된 정확도로 보기 어렵다.
